## About

A **Visual Inertial Odometry (VIO)** pipeline that fuses camera and IMU sensor data to estimate 6-DoF pose in real time. Combines visual feature tracking with inertial measurements for robust localization in GPS-denied environments.

---

## Features

- Feature detection and optical flow tracking (KLT / ORB)
- IMU pre-integration for fast inter-frame motion estimates
- Tightly-coupled sensor fusion
- Real-time 6-DoF pose estimation
